SYSTEM ARCHITECTURE

Sub-30ms Real-Time Data Pipeline

End-to-end telemetry flow from visitor's camera to host's 3D desktop canvas.

01
CAPTURE

Webcam Ingestion

Captures raw video frames via getUserMedia at 640x480 resolution on the Visitor browser.

02
EXTRACTION

Pose Calculation

MediaPipe calculates 3D Euclidean distances for mouth openness, eyelid ratios, and Euler rotation angles.

03
RELAY

Socket.IO Pipe

Node.js server routes visitor:faceUpdate telemetry packets directly to Host room at throttled 30 FPS.

04
RENDER

Three.js Overlay

Host WebGL canvas interpolates target rotations and renders 3D head hovering over the 2D desktop.

🛡️ Built-in Resilience & Fallback Mode: If webcam access is blocked or unavailable, the app automatically switches to interactive mouse-tracking & hotkeys (M for mouth, B for blink).

Slide 05 / 08
ENGINEERING CHOICES

Technology Stack & Technical Decisions

Purpose-built for zero loading latency, high frame rates, and zero install friction.

FRONTEND ENGINE

Graphics & Vision

  • ✓ Three.js r128: WebGL 3D procedural geometry with zero external asset loading delay.
  • ✓ HTML5 2D Canvas: High-performance retro desktop renderer running at 60 FPS.
  • ✓ MediaPipe FaceMesh: Lightweight client-side vision pipeline in WASM.
  • ✓ Vanilla JS: Zero heavy framework overhead (no React/Vue bundle lag).
BACKEND & SOCKETS

Server & Networking

  • ✓ Node.js + Express: Ultra-fast HTTP server serving client assets and health checks.
  • ✓ Socket.IO 4.6: Bidirectional WebSocket communication with sub-30ms latency.
  • ✓ In-Memory Room Store: Ephemeral session routing with zero database overhead.
  • ✓ CORS Enabled: Ready for public tunneling and multi-origin hosting.
DEPLOYMENT

Hosting & Distribution

  • ✓ Cloud Ready: Ready for one-click deployment on Render, Railway, or Glitch.
  • ✓ Tunneling Support: Instant worldwide testing via ngrok http 3000.
  • ✓ Docker Support: Preconfigured Dockerfile & .dockerignore for containerization.
  • ✓ Zero Dependencies to Run: Anyone with a browser can join via link.
